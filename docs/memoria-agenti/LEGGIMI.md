# Memoria degli agenti Claude Code

Copia della memoria condivisa delle sessioni (frontend, backend, due-app) presa l'8/10/2026,
per non perderla cambiando PC. Su un PC nuovo si ripristina copiando questi file (tranne
questo LEGGIMI) in:

    %USERPROFILE%\.claude\projects\<percorso-del-progetto>\memory\

dove `<percorso-del-progetto>` è il percorso della cartella del repository con `\` e `:`
sostituiti da `-` (es. `C--Users-andre-Desktop-MondoDelRisparmio`).

Le note di consegna complete sono in docs/CONSEGNE_FRONTEND.md (questo branch),
docs/CONSEGNE_BACKEND.md (branch worktree-backend-api-docs) e docs/CONSEGNE_DUE_APP.md
(branch worktree-desktop-due-app).
